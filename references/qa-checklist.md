# 交付前检查清单

## 粗剪
- [ ] 复核转写里没有重复句、半截话、"重来 / OK / 这段不要"
- [ ] 句首没有吃字，句尾没有切掉尾音（抽查每个切点前后 1 秒）
- [ ] 句子之间没有过长的停顿（>0.65s 的都已压缩）

## 字幕
- [ ] 和实际口播逐字一致
- [ ] 产品名、人名、术语都联网核对过
- [ ] 拿不准的已列进交付说明
- [ ] 一屏一句，没有超出底条，没有跨屏断词

## 画面（预览图联系表 + 成片每 3 秒一帧联系表）
- [ ] 每个场景都能回答"这个画面给了观众什么口播之外的信息"
- [ ] 没有禁止项：
  - 对错框 / 勾叉 / 删除线
  - 把原话装框
  - 英文长段落截图当解释
  - 截图带网址
  - 空白页截图
- [ ] 全屏场景入场 0.3s 内有主体，没有先出一个空框再等内容
- [ ] 文字不压脸、不压字幕区（y>920）、不出画
- [ ] 口播上的文字有暗渐变垫底
- [ ] 分屏左右交替，口播出镜大约一半
- [ ] 截图 / 官方素材里没有最高级、"首个"、排名（例如 "World's First"、"most capable"、"#1"）
- [ ] 转场帧（进出场的那 0.3 秒）没有穿帮、闪黑、残影

## 音频
- [ ] 整体 -16 LUFS（±0.5），真峰值不超过 -1.5 dBTP
- [ ] 有人声时配乐让开，章节处换曲自然
- [ ] 音效不过密，没有和人声重点字撞在一起

## 事实与合规
- [ ] 口播事实核实表已完成：说法 / 结果 / 依据
- [ ] 核实不了的说法没有出现在画面上
- [ ] `scan.py` 没有 BLOCK
- [ ] 每条 REVIEW 都写了判断
- [ ] 素材、截图、官方素材来源都已登记，授权说明完整

## 剪映草稿（如果导出）
- [ ] `check_env.py` 的剪映项全部通过
- [ ] 草稿里媒体没有缺失，字幕字体路径存在
- [ ] **有一条名为「人声」的独立音频轨**（人声.wav 非静音）；口播视频本身静音——不要依赖视频自带音轨出声
- [ ] 口播素材是 1920×1080（原片带黑边时 project.json 要有 `aroll_vf`），草稿画布是 1920×1080
- [ ] 字幕素材 `check_flag` 含背景位 16（否则黑色半透明底条不显示）
- [ ] 包装层是用带 alpha 清理的 `render.py overlay` 渲染的
- [ ] 返修时按用户要求更新草稿（默认原地更新现有草稿）（有 `.tthe_backup/` 备份），避免产生用户不需要的多余版本
- [ ] 提醒用户：外接盘要插着；用户在剪映里手动改过草稿时，先问再原地更新（会覆盖手动修改）
