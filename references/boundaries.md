# 边界与拒绝项

## 适用范围

**适用**：

- 单人口播（坐着或站着对镜头）。
- 内容是 AI 科普、AI 工具 / 产品介绍、科技资讯、教程讲解。
- 横屏 1920×1080、30fps，中文为主。

**不适用，或需要改造后再用**：

| 情况 | 原因或处理 |
|---|---|
| 竖屏 9:16 | 版式需要整体重排，`lib.js` 的坐标都是按横屏写的 |
| 多机位、访谈、对谈 | 粗剪逻辑只按单人口播设计 |
| Vlog、剧情、带货 | 风格和合规要求不同 |
| 纯录屏教程 | 没有口播人物，分屏和推镜不适用；可以只用全屏场景 |
| 超过 15 分钟的长片 | 渲染时间和包装层体积都按时长线性增长：渲染约 7 帧/秒，包装层约 2.5 GB/分钟 |

## 画面手法：禁止项

以下做法默认禁止；如任务确有特殊需求，应先核实事实、授权和发布语境，再按用户明确要求处理：

1. **对错框 + 打勾打叉 + 删除线**：红框绿框、✓ ✗、"不是 ~~新模型~~"这类表现方式。概念对比请改用结构图（例如分层图）。
2. **无信息增量的词句展示**：把口播原话放进框、胶囊或要点行里。字幕已经有了，再框一遍是重复。
3. **英文长段落截图当解释**：观众看不懂，也不知道它在说什么。要解释就配官方演示画面、B-roll 或中文流程图。
4. **截图带网址**：浏览器框只留三个圆点。出处写进交付说明。
5. **空白页截图**：只有 logo、大片留白、没有信息量的页面。
6. **截图或官方素材里出现最高级、"首个"、排名**，例如 "World's First"、"most capable"、"#1"、"first AI agent"。裁掉，或者换一段。
7. **静止贴图**：没有入场、出场动效的元素。
8. **逐句切画面**：一句话换一个画面，节奏碎，也没有重点。

## 内容：拒绝做的事

遇到这类请求直接拒绝，并说明原因：

- **伪造或篡改证据**：
  - 编造新闻截图
  - 修改官网截图里的文字、价格、日期
  - 拼接成官方没说过的话
  - 用"官方截图"的样式呈现自己写的内容
- **编造事实**：
  - 编造产品功能、价格、发布日期、用户数、排名、测评数据
  - 把示意画面伪装成真实界面（示意画面必须标"示意"）
- **冒充**：冒充官方账号或媒体，伪造机构背书或合作关系。
- **人像与声音**：用生成式 AI 合成真人肖像、换脸、克隆声音，放进视频冒充真实画面。
- **侵权素材**：
  - 去水印
  - 使用来源不明的影视、音乐片段
  - 把付费素材当免费素材用
- **隐私**：公开他人的联系方式、聊天记录、后台数据等可识别隐私。
- **高风险领域的结论性内容**：股票个股推荐、医疗疗效、法律结论等。这类请求转给用户自己判断，不由本 skill 生成可发布稿。

## 事实核验底线

- 口播里的**产品名、功能、价格、日期、数据**，包装前都要联网核实。顺序是：先查官网 / 官方帮助中心，再查一线媒体报道。
- 核实结果写进交付说明的事实核实表，分三栏：说法 / 结果 / 依据。
- **核实不了的**：不上画面，只保留在口播和字幕里，并在交付说明里标"没找到出处"。
- **和官方冲突的**：以官方为准修正字幕，再提醒用户补录。例子：口播说的"Q"，官方名称是 Cue。
- 截图、官方素材必须来自原始页面，不能二次加工里面的文字。只允许裁切、缩放、高亮框、压暗。

## 授权底线

| 类别 | 可用来源 | 要求 |
|---|---|---|
| B-roll / 配乐 / 音效 | Mixkit（逐条核验适用许可；免费许可的使用范围依其条款）；用户自有素材；用户提供并确认过授权的素材 | 每条都登记来源（`index.jsonl` / `LICENSES.md`） |
| 官方演示视频、产品图、网页截图 | 新闻评论中的引用 | 保持原貌，不显示网址，在交付说明列出处；建议在发布简介里注明"产品画面来自 XX 官方发布" |
| 产品 Logo | 不单独使用（规避商标问题） | 只在官方截图 / 素材里自然出现 |
| 字体 | 得意黑（OFL）、系统字体 | — |

## 合规扫描的边界

- `scan.py` 只扫字幕和画面文字。默认规则参考《广告法》绝对化用语和常见平台风控词，可以在 project.json → scan 里按账号加严。
- **自动扫描通过 ≠ 平台一定过审**。交付说明里只能写"已按当前规则完成风险扫描"。
- **人工必看**：截图和官方素材里的文字、官方宣传视频是否需要在简介注明来源、AI 生成内容标识。
- **商业推广**：内容构成广告或合作推广时，要提醒用户使用平台的商业标识。
