# 踩过的坑

真实项目里遇到过的问题，以及原因和处理方法。

## 转写与粗剪

| 现象 | 原因 | 处理 |
|---|---|---|
| 逐字时间越往后偏差越大（片尾偏 20 多秒） | whisper.cpp 开了 `--vad`：整句时间换算回原片了，逐字时间没有 | 不开 VAD；转写后自检 |
| 切点吃字，或者气口几乎没有 | 用 Whisper 逐字时间卡边界（相邻字的时间首尾相连） | 边界只按 silencedetect 定 |
| 粗剪后还残留重复句 | Whisper 把几遍录音识别成一句长句 | 粗剪后必须重新转写复核 |
| 产品名识别错（"Q"、"道次"、"Glockbolt"） | 同音，加上英文专名 | 在 `asr_prompt_terms` 里写上专名；**联网查官方名称**（"Q" 实际是 Cue） |

## 渲染引擎

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面报错 `h is not a function` | 组件参数取名 `h`，遮蔽了全局的 `h()` | 参数不要用 `h` |
| 连续两个分屏左右换边时，人物瞬移 | 关键帧从"上一个目标值"插值，而不是从"当前实际位置"插值 | `arollState` 已改成从实际位置过渡 |
| 截图高亮框的四周没有压暗 | 用 `clip-path` 做描边动画时，把 box-shadow 一起裁掉了 | 压暗层和描边层分成两个元素 |
| 截图推近后，段落左侧被裁掉 | 裁切宽度没有给推近留余量 | 裁宽 = 框宽 × 推近倍数 + 80 |
| 渲染中途截图超时 | 机器负载高（并行进程太多，又同时开了其他浏览器） | 截图超时 120s 并自动重试 3 次；并行数用 5 |

## 素材

| 现象 | 原因 | 处理 |
|---|---|---|
| 联系表拼到一半中断 | 个别缩略图是 0 字节或尺寸不一致，ffmpeg concat 中断 | 每张先单独统一成 320×180，再用序列拼 |
| 素材下载卡死 | 1080p 文件大、网络慢、单请求重试太久 | 用 curl 并行下 720p（全屏会压暗，卡片也小，够用） |
| 官网截图打不开、被拦 | 有地区限制，或站点在当前网络打不开 | 换官方帮助中心或一线媒体报道；仍然打不开就换来源，并在交付说明写明 |
| 截图被弹窗、cookie 横幅挡住 | 页面浮层 | `shot.py` 自动按 Esc、点关闭按钮、删除 fixed 浮层 |
| 截图定位不到原句 | 句子被链接或加粗拆成了多个文本节点 | 按"包含该句的最小可见元素"定位 |
| 官方新闻稿标题含 "World's First" | 官方宣传用语也是最高级 | 裁掉标题，或者换段落 |
| 官网首页只有 logo，大片空白 | 首屏是品牌页 | 用 `imgs.py` 找页面里的演示视频和产品图 |

## 音频

| 现象 | 原因 | 处理 |
|---|---|---|
| 混音报错 `afade st out of range` | 片子比配乐表短，第二首配乐的起点在片尾之后 | 跳过起点晚于片尾的配乐段 |
| 分轨导出时测不到响度 | `-filter_complex` 的输出不能再接 `-af` | 把 ebur128 放进滤镜图里 |

## 剪映

| 现象 | 原因 | 处理 |
|---|---|---|
| 打开草稿没有人声 | 剪映不稳定地读取脚本写入视频素材的自带音轨：先是 `has_sound_separated=true`，改掉后字段全对仍无声 | 口播视频静音，人声 `人声.wav` 独立成「人声」音频轨（`jianying.py` 已改）；交付前确认草稿里有「人声」轨 |
| 口播前有一条竖向虚线 | Chrome 透明截图在渐变淡出处有"几乎透明但颜色极亮"的抖动像素，剪映合成时会显示出来 | `render.py overlay` 会清理 alpha < 24 的像素 |
| 改过的草稿读不了 | 剪映保存后会把草稿加密 | 不要重新生成草稿；修素材就原地替换同名文件 |
| 字幕字体不对 | 剪映缓存里没有这个字体 | 先在剪映里用一次得意黑 |
| 画布不是 16:9，下方一条黑边 | 草稿画布取口播素材尺寸；原片带黑边或非 16:9（如 3024×1964 录制）时，`export_aroll.py` 没裁就导出 | project.json 写 `aroll_vf`（如 `crop=3024:1696:0:134,scale=1920:1080,`），prep 与 export_aroll 都会先裁；导出后 ffprobe 确认口播是 1920×1080 |
| 字幕没有黑色半透明底条 | 只写了 `background_*` 字段，没打开文字素材 `check_flag` 的背景位（16） | `jydraft.add_text` 按 7 基础 / 8 描边 / 16 背景 / 32 阴影 计算 check_flag |

## 工作习惯

- zsh 里 `set -- $var` 不会按空格拆分；在 bash 里跑，或者显式写 `${=var}`。
- 删除文件前先确认路径，大批量删除交给用户决定。
- 长任务（渲染 10+ 分钟）放后台跑，同时做下一步的准备工作（写说明、导出文字、扫描）。
