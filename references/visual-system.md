# 视觉系统（科技风）

样式都在 `scripts/engine/stage.template.html` 的 `:root` 和类名里，改那里会对全片生效。

## 颜色

| 名称 | 值 | 用途 |
|---|---|---|
| `--bg` | #05070d | 底色 |
| `--cyan` → `--violet` | #4cc9ff → #9b8cff | 主强调色：渐变线、高亮字、节点、进度条 |
| `--mint` | #3ee6a8 | 正向状态、在线标签 |
| `--amber` | #ffc85a | 提示、限制条件（例如需要邀请码） |
| `--red` | #ff6b7a | 只在极少数警示里用。**禁止拿来做"对错"对比** |
| `--mute` | 白 62% | 次要文字 |

## 玻璃卡

- 背景 rgba(16,20,34,.62)，背景模糊 28px，饱和度 140%。
- 1px 白色 12% 描边，圆角 30px，深投影。
- 顶部有一条 3px 的青紫渐变线。

## 字体

| 用途 | 字体 |
|---|---|
| 字幕、大标题 | 得意黑（Smiley Sans Oblique）|
| 中文正文 | 苹方（PingFang SC）600 |
| 英文 / 数字 | SF Pro Display 700–800 |
| 小标题 | 英文全大写，字距 0.32em，青色，前面加发光圆点 |

## 全屏场景背景

- 素材压暗到 25–60%（`dim`），按需加模糊（`blur`）。
- 叠一层径向暗角（`tint`），可选叠 80px 网格。
- 背景从 1.04 缓推到 1.09。
- 全片加颗粒（overlay 混合，不透明度 7%）和暗角。

## 分屏

- 人物让位 330px。
- 面板一侧加暗渐变垫底：97% → 45%，到 60% 处变透明。
- 面板内容从 x=50–90 起排，宽度不超过 740。

## 截图卡（浏览器框）

- 深色标题栏，只有三个圆点，**不显示网址**。
- 截图按 2 倍像素采集。高亮框是 3px 青色描边，带外发光，四周压暗 50%。

## 官方演示卡

- 手机竖屏演示裁成 420×878，圆角 36。
- 横屏演示卡 740×416，圆角 22，浅色底。
- 中文注释气泡：深色玻璃底，`who` 一行青色小字。用户一侧（`me`）用蓝紫渐变底。
